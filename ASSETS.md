- Pembuat/pemegang hak cipta: **Cesium, © 2017**.
- Sumber resmi distribusi: [KhronosGroup/glTF-Sample-Assets — RiggedFigure](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/8f492390ddc7a2ae221a1369ef560589cf8c70fb/Models/RiggedFigure).

- Berkas model: `src/assets/rigged-figure.glb` (50.116 byte).
- Salinan keterangan sumber: `src/assets/rigged-figure-source.md`.
- Teks lisensi: `src/assets/CC-BY-4.0.txt`.
- Model didistribusikan ulang tanpa perubahan berkas. Penyesuaian skala, posisi, warna material, dan efek dapat diterapkan saat dirender dalam permainan.
- Tidak ada afiliasi atau dukungan dari Cesium maupun Khronos yang tersirat.

Model merupakan karakter manusia low-poly tanpa fitur wajah, berkulit tulang (skinned), dengan satu klip animasi. Tidak memerlukan tekstur eksternal, Draco, atau KTX2. Cocok untuk siluet pelanggan/penampakan bergaya stylized. Klaim lisensi diperiksa langsung pada README resmi untuk model ini; bukan disimpulkan dari lisensi umum repositori.

Commit sumber: `8f492390ddc7a2ae221a1369ef560589cf8c70fb`.

SHA-256 model: `d6be85417d3e256861ee733eea6916093a7af7c79c16366181fd8abcaeb38cf5`.
